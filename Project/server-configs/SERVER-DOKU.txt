================================================================================
KONFIGURATIONSVORLAGEN (nicht in diesem Verzeichnis)
================================================================================

Die folgenden Dateien muessen pro System manuell erstellt werden und liegen
NICHT im Git. Vorlagen befinden sich an diesen Stellen:

  Backend/.env.example        -> Backend/.env
    Enthaelt: SHEET_ID, PORT, COURT_URL, GOOGLE_APPLICATION_CREDENTIALS

  Frontend/JS/SDK.js.example  -> Frontend/JS/SDK.js
    Enthaelt: BACKEND_WS_URL (WebSocket-URL pro System)

Zusaetzlich wird pro System ein Google Service Account Key benoetigt:
  Backend/service-account.json (JSON-Key von Google Cloud Console)


================================================================================
INSTALLATION AUF DEM SERVER
================================================================================

Caddyfile:
  cp Project/server-configs/Caddyfile /etc/caddy/Caddyfile
  systemctl reload caddy

Systemd-Services:
  cp Project/server-configs/systemd/*.service /etc/systemd/system/
  systemctl daemon-reload
  systemctl enable --now epiber-piber epiber-paj epiber-pk
